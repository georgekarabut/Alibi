# Алиби

Лендинг барбершопа «Алиби», Краснодар, ул. Воронежская, 47/14, ЖК «Фонтаны».

Сайт: https://alibi-krd.ru/ (основной адрес, на него указывает canonical), копия на https://georgekarabut.github.io/Alibi/

## Структура

| Путь | Что это |
|---|---|
| `index.html` | Вся разметка, разметка для поиска (организация и частые вопросы; ответы в FAQPage должны совпадать с видимым текстом) и встроенные скрипты: карусель отзывов, плавающая кнопка записи на телефоне, мини-игра на первом экране |
| `styles.css` | Все стили. Основные цвета заданы переменными в `:root` |
| `privacy.html` | Политика конфиденциальности, ссылка на неё в подвале. Шапка и подвал повторяют главную, при их изменении править обе страницы |
| `assets/images/` | Логотип, иконки сайта, картинка для превью в соцсетях `og-image.jpg` (1200×630), картинки мини-игры, фото галереи `gallery-*.webp` и входа `entrance.webp` (из карточки на Яндекс Картах) |
| `robots.txt`, `sitemap.xml` | Для поисковиков. При изменении страницы обновлять `lastmod` в sitemap |
| `assets/fonts/` | Шрифты Renaissance и AlibiSign |
| `licenses/` | Лицензия шрифта Renaissance |
| `dist/alibi-preview.html` | Автономная копия страницы одним файлом, собирается автоматически |
| `wrangler.jsonc` | Настройка публикации через Cloudflare |
| `.assetsignore` | Файлы, которые Cloudflare не отдаёт посетителям: `.git`, `.github`, README, настройки |

## Мини-игра на первом экране

Посетитель «стрижёт» гостя: проводит курсором или пальцем по волосам и бороде, и они отпадают локонами.

- `game-after.webp` — итоговый вид: фейд и аккуратная борода.
- `game-locks.webp` — слой «до»: обросшие волосы и лохматая борода, всё остальное прозрачно.
- `game-locks-map.png` — карта локонов в половинном разрешении: номер локона в каналах R и G (`id = R + G·256`), маска волос в канале B.

Иллюстрации сгенерированы в Kling. Чтобы заменить картинки, нужно пересобрать слой «до» и карту локонов так, чтобы они совпадали с итоговым видом пиксель в пиксель.

## Портреты мастеров

Фото мастеров на странице пока нет, места под них скрыты. Чтобы портрет появился, положите вертикальное фото (от 900×1200) в `assets/images/master-tanya.webp` или `assets/images/master-ali.webp`: скрипт найдёт файл и покажет его в карточке мастера, менять разметку не нужно.

На alibi-krd.ru фото галереи и портреты, как и картинки игры, загружаются с GitHub Pages: российские провайдеры обрывают соединения с Cloudflare примерно после 16 КБ.

## Просмотр

Откройте `index.html` через локальный HTTP-сервер (мини-игре нужен доступ к картинкам), например:

```
python -m http.server 8080
```

и затем http://localhost:8080.

## Публикация

- **GitHub Pages:** публикует ветку `main` автоматически после каждого push.
- **Workflow `build-preview.yml`:** после изменений в `index.html`, `styles.css` или `assets/` пересобирает `dist/alibi-preview.html` и коммитит его в `main`. Картинки мини-игры загружаются скриптом и в автономную копию не встраиваются, поэтому игра работает только на сайте.
